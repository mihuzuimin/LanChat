The single-file LanChat release embeds FFmpeg Windows x64 binaries distributed
under the GNU Lesser General Public License, version 2.1 or later (LGPL-2.1+).
The FFmpeg license text is provided in FFmpeg-LICENSE.txt. The FFmpeg project

FFmpegDotNet.bin.winx64 9.0.2 NuGet package. This application invokes the

cache when the H.264 path is first used.
